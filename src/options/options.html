Configurações

O cronômetro do painel fica amarelo ao passar disso.
Evita que uma matéria com 3 questões apareça como "sua pior".
Em dias diferentes a mesma questão sempre conta de novo — é revisão.
Viram os botões do cronômetro no painel. Use um valor curto (ex.: 1) para testar.
Sem mouse, teclado ou scroll por esse tempo, o cronômetro para sozinho e retoma quando você volta.
O gabarito fica escondido até fechar o bloco; aí sai o resultado consolidado.

Dados

Tudo fica no seu navegador (chrome.storage.local). Nada é enviado para servidor nenhum.
